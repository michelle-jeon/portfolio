# Portfolio
개인 포트폴리오 웹사이트입니다.
프론트엔드 개발자로서 참여한 실무 프로젝트를 소개하고, 사이드 프로젝트와 학습 내용을 기록합니다.

## Live demo
[배포 링크] https://frontend-mikyeong-jeon.vercel.app/

## Features
* 프로젝트 소개 : 진행했던 주요 프로젝트와 토이 프로젝트 정리
* 비주얼 섹션 : 그리드와 애니메이션을 이용한 자기 소개

## Tech stack
* Framwork : React, Vite
* Language : Typescript
* Styling : Styled-components
* Deployment : Vercel
* Tools : ESLint, Git/Github

# Getting started
## 저장소 클론
git clone https://github.com/michelle-jeon/portfolio.git
cd portfolio

## 패키지 설치
npm install

## 개발 서버 실행
npm run dev

## 프로덕션 빌드
npm run build
